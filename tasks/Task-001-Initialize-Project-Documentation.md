# Task 001 — Initialize Project Documentation

Read the **Context System Design v0.1** framework and the **Mood-Based Spotify Playlist Generator design document** before beginning this task.

Using those documents as the design context, initialize the project documentation.

Create:

* `AGENTS.md` — the instructions and operating context for AI agents working on this project.
* `README.md` — the project documentation and overview.

You may also create **any additional files you determine are necessary** based on the framework and design documents.

Do not implement the application yet. The purpose of this task is to establish the project's documentation, agent context, and any supporting artifacts needed for future development.

Use your judgment about what belongs in each file and how the project should be structured. Follow the principles of Context System Design when making those decisions.

The resulting files should provide enough context for an AI agent to understand the project and continue development without relying on this conversation.
